# KSTDC — "Karnataka, Your Way" 🌿
### Build What Moves India · Flagship Citizen Experience Redesign

An official, citizen-first digital travel platform for the **Karnataka State Tourism Development Corporation (KSTDC)**. Built with **Astro 5+**, **React 19 Islands**, and **Tailwind CSS v4**, directly adopting the clean, minimalist product design system from [DESIGN-meta.md](file:///c:/Users/Admin/Desktop/KSTDC/DESIGN-meta.md).

---

## ✨ Features & Citizen Services

1. **4-in-1 Multi-Service Intent Selector**:
   - 🚌 **Conducted Tour Packages**: Southern & Northern Circuits, UNESCO Heritage, Western Ghats Escapes.
   - 🏨 **Hotel Mayura Stays**: Verified government-owned properties with direct citizen tariffs.
   - 🚖 **KSTDC Airport Taxi & Cabs**: 24x7 prepaid airport transfers (BLR) and outstation chauffeur fleet.
   - 🏛️ **City Sightseeing & Activities**: Ambaari open-top double-decker bus tour & Vidhana Soudha guided walks.

2. **Decision-Reduction AI Trip Planner ("Plan My Trip")**:
   - Natural language input matching live KSTDC routes and Mayura rooms with 0% hallucination.
   - Grounded matching explanations (e.g. *Why this trip fits your budget, companions, and pacing*).

3. **Visual Route Timelines & Transparent PDPs**:
   - Hour-by-hour route stops, halts, meals, and viewpoint indicators.
   - Pacing balance breakdown (Travel Time vs Sightseeing vs Rest).
   - Upfront all-inclusive pricing with zero hidden surcharges.

4. **3-Step Streamlined Express Checkout**:
   - Departure calendar with live seat availability & Bengaluru pickup points.
   - Passenger counters with 5% senior citizen concession and mobility assistance flags.
   - Itemized GST calculation and simulated instant UPI QR / Card / NetBanking payment.

5. **Travel Companion & Digital Wallet**:
   - Digital boarding pass ticket with unique booking ID.
   - Google Maps pickup directions, `.ics` calendar sync, and WhatsApp itinerary share.
   - Interactive local Kannada audio phrasebook and weather advisory.
   - Persistent citizen wallet under `/my-bookings`.

## 🛠️ Tech Stack

- **Framework**: [Astro 5+](https://astro.build/) (Static Site Generation)
- **UI Islands**: [React 19](https://react.dev/) (`@astrojs/react`)
- **Styling**: [Tailwind CSS v4](https://tailwindcss.com/)
- **Icons**: [Lucide React](https://lucide.dev/)
- **Design Tokens**: Warm Canvas, Saturated Cobalt Blue (`#0064E0`), Crisp Black Pill Buttons, 28–32px Card Radii.

## 🚀 Getting Started

```bash
# Clone the repository
git clone https://github.com/Chethankumar443/kstdc.co.git
cd kstdc.co

# Install dependencies
npm install

# Start local development server
npm run dev

# Build for production (25 static pages)
npm run build
```
